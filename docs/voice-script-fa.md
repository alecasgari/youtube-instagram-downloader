# اسکریپت ویس — ساخت دانلودر یوتیوب و اینستاگرام (محاوره‌ای)

> برای ضبط پادکست / ریل / ویدیوی آموزشی. با لحن خودت بخوان؛ جمله‌ها راهنماست، لازم نیست کلمه‌به‌کلمه.

---

## شروع (۱۵ ثانیه)

سلام. تو این ویدیو می‌خوام برات تعریف کنم چطور برای سایت دکتر گیو شریفی — givsharifi.com — یه سیستم ساختیم که با یه پیام تلگرام، ویدیو از اینستاگرام یا یوتیوب دانلود می‌شه، می‌ره روی کلود، و خودکار توی سایت منتشر می‌شه.

و جدا از اون، یه پنل وب ساده هم داریم که خودمون لینک می‌دیم و دانلود می‌کنه — با رمز.

---

## مشکل اولیه (۳۰ ثانیه)

قبلاً ویدیوها دستی دانلود می‌شدن، آپلود دستی به Cloudflare R2، و JSON سایت دستی آپدیت می‌شد. برای هر ریل اینستاگرام چند مرحله طولانی.

هدف این بود: از تلگرام فقط لینک بفرستی — بقیه‌ش خودکار.

---

## معماری کلی (۴۵ ثانیه)

جریان اینه:

**تلگرام** → ربات منو داره → **n8n** روی VPS اجرا می‌شه → به سرویس **giv-ytdlp** وصل می‌شه → اون با **yt-dlp** ویدیو و پوستر رو می‌گیره → می‌ذاره توی **Cloudflare R2** → بعد **Gemini** عنوان و توضیح انگلیسی می‌نویسه → **GitHub** فایل `video-library.json` آپدیت می‌شه → سایت استاتیک از GitHub Pages دیپلوی می‌شه.

یعنی سه لایه: ربات، اتوماسیون، و سرویس دانلود.

---

## چرا سرویس جدا؟ (۳۰ ثانیه)

اول کد دانلودر داخل ریپوی سایت بود. مشکل: هر بار تغییر کوکی یا Docker باید کل پروژه سایت قاطی می‌شد.

جدا کردیم به ریپوی **`youtube-instagram-downloader`** روی GitHub. سایت (`givsharifi-website`) فقط ورکفلو n8n و JSON ویدیوها رو نگه می‌داره.

روی سرور: `git pull` برای کد — فقط کوکی‌ها با `scp` یک‌بار می‌رن، چون secret هستن.

---

## تکنولوژی سرویس دانلود (۱ دقیقه)

- **Python 3.12** — سبک، بدون فریم‌ورک سنگین
- **yt-dlp** — دانلود از یوتیوب و اینستا
- **ffmpeg** — ادغام ویدیو و صدا
- **Deno** — از ۲۰۲۶ یوتیوب برای حل challenge لازمه
- **Docker** — کانتینر `giv-ytdlp` روی شبکه داخلی `giv-ytdlp-net`
- **boto3** — آپلود به R2 مثل S3
- **UI** — HTML/CSS/JS ساده، فارسی، با رمز

API برای n8n: `POST /download` — UI برای انسان: `/` با رمز و `POST /api/ui-download`.

## دردسر یوتیوب و cookies (۴۵ ثانیه)

اینستاگرام روی سرور اغلب بدون کوکی کار می‌کنه. یوتیوب روی VPS Contabo تقریباً همیشه می‌گه «ثابت کن ربات نیستی».

راه‌حل: از Chrome با افزونه **Get cookies.txt LOCALLY** export می‌کنیم — یوتیوب و اینستا جدا — بعد اسکریپت `merge-cookies.py` یک فایل می‌سازه، با `scp` می‌ره سرور، `install-cookies.sh` داخل کانتینر می‌ذاره.

کوکی‌ها توی Git نیستن — عمداً.

---

## n8n و تلگرام (۳۰ ثانیه)

ورکفلو `02-publish-video` لینک می‌گیره، به `http://giv-ytdlp:9876/download` POST می‌زنه — فقط از داخل Docker network، نه از اینترنت.

Gemini متن انگلیسی SEO می‌نویسه. GitHub `video-library.json` رو با SHA درست edit می‌کنه — یه باگ JSON خالی داشتیم که با HTTP Request به GitHub API حل شد.

---

## UI و امنیت (۳۰ ثانیه)

پورت 9876 فقط روی `127.0.0.1` سرور بازه — نه برای کل اینترنت.

از لپ‌تاپ با **SSH tunnel** UI رو باز می‌کنیم: `ssh -L 9876:127.0.0.1:9876` و بعد `http://127.0.0.1:9876`.

رمز UI توی `.env` هست: `GIV_YTDLP_UI_PASSWORD`. مسیر `/download` برای n8n از بیرون block می‌شه وقتی دامنه عمومی بذاریم.
